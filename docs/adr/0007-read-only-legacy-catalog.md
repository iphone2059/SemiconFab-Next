# ADR-0007 — 只读设备目录与可校验导入资产

- 状态：已采纳（2026-10-24）
- 关联：ADR-0006、MIG-01/MIG-02

设备型号目录属于 M03，与实际机台和 Run 状态分开。单一 `fab_app` 增加 `Fab.Catalog` 命名空间，架构检查明确允许该命名空间；项目数、项目依赖和无第三方包约束保持现状。

旧目录、OEM/OSAT 原始库、价格/BOM、布局、Schema 和许可通过标准库 Python 工具导入到内容哈希命名的不可变目录；完整原文件按字节保存。`current.json` 仅在结构和引用检查没有错误时原子切换；重复输入不重复生成版本，拒绝记录可追踪。哈希用于完整性和版本追踪，不是来源真实性签名。

API 只读取已发布快照，缺失或校验失败返回 503，不能返回伪造的空目录。开发版沿用现有身份与 Development 限制，不开放导入写接口。发布产物包含导入资产，不依赖旁边仍存在旧仓库。

新 DTO 的 `record/legacy/price` 为明确的开放 JSON 对象，由同一 JSON Schema 生成 C# `JsonElement` 和 TS 只读对象；保留未知字段和来源。既有 L1/draft 标签是历史标签；本次结构检查不声称重新执行完整设备 Schema 校验或行业认证。完整 L1/L2/L3 双语校验仍单独跟踪。
