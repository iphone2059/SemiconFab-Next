- 页面模块：`web_app/src/features/twin`（twin-page + controllers/ + state/ + HUD 子组件）、`features/catalog`（catalog-page/data/search/labels/types + components/controllers/export/state）、`features/workbench`（workbench/command-console + components/controllers/state）。

- 装配与路由：`app/providers`、`app/router`（`app/router/routes` 是唯一允许组合 features 的装配入口；通用 router 文件不得 import features，R2/R7）。
- 数据与状态：HTTP 经 `api/transport/http.ts`（唯一策略）与 TanStack Query；客户端 UI 状态为 7 个类型安全 Zustand store（feature store 在 `features/*/state/`，共享在 `state/`）。
- 门禁：R7（通用层不 import features）、R12（公共组件跨 feature/设计系统角色）、R13（空依赖 effect 稳定原语）、R14（无未登记 `any`/伪校验）；测试镜像布局 `web_app/tests/features/**`、`tests/components/**`、`tests/state/**`。
