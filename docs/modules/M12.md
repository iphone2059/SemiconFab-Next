## 实际归属（2026-10-29 Effect 4 终态）

- 应用侧场景端口：`web_app/src/contracts/scene.port.ts` 的 `ScenePort`（必需 `SceneCommands`、强类型 `SceneMountOptions`、判别式 `SceneMountOutcome`、只读 `SceneLifecycleEvent`）。
- 实现（严格单层）：`web_app/src/rendering/lite-backend.ts`（ScenePort Lite 实现：WebGPU 获取/首帧/设备丢失恢复/幂等 mount-dispose）+ `rendering/lite-*.ts`（runtime/world/lighting/effects/xray/cut/wafer 等独立资源所有者）。无 `rendering/lite/` 二级目录。
- 生成数据合同：`rendering/static-structure-data.ts` 类型合同；`generated/static-structure-packed.ts` 由 `tools/pack_static_structure.mjs` 生成并登记于 `tools/generated-artifacts.json`。
- 生命周期：`state/runtime-store.ts` 的 `ViewerLifecycle` 是控制流唯一依据；GPU 对象不进入 AtomRegistry/Resource Atom。
- 高频通路：遥测 SSE → `realtime/telemetry-runtime.ts` → Worker → `realtime/frame-ring-buffer.ts` → 渲染 frame loop；100ms UI 合批在 `realtime/` + `twin/` 边界，逐帧数据不触发 React state。
- 门禁：ARCH-11/`architecture-contract-rules.test.ts`（渲染层不 import React/Query/Atom/XState/features）；A4 真实 Chrome/WebGPU A/B 证据在 `docs/architecture/evidence/perf/`。
- 测试：`web_app/tests/{rendering,performance,integration}/**`；设备丢失/生命周期由渲染测试覆盖。

本次重构后的实际实现状态见 `../IMPLEMENTATION-STATUS.md` 与 `../architecture/README.md`。
