## 实际归属（2026-10-28 递归整改后终态）

- 应用侧场景端口：`web_app/src/application/ports/scene.ts` 的 `ScenePort`（`SceneCommands` 全部必需、强类型 `SceneMountOptions`、判别式 `SceneMountOutcome`、只读 `SceneLifecycleEvent`；R9 禁止 silent optional 能力）。`rendering/fab-scene.ts`/`SceneFacade` 已删除。
- 实现：`web_app/src/rendering/lite-backend.ts`（ScenePort 的 Lite 实现，含 GPU 获取/首帧/设备丢失恢复/幂等 mount-dispose）+ `rendering/lite/**`（Babylon Lite 运行时、几何、光照、选择、裁剪、动影、airflow）；`rendering/lite/effects/{xray,xray-shaders,cut,wafer,index}.ts` 为独立资源所有者（R-06）。
- 生成数据合同：`rendering/contracts/static-structure-data.ts`（手写类型合同）；`generated/static-structure-packed.ts` 由 `tools/pack_static_structure.mjs` 生成并登记于 `tools/generated-artifacts.json`（R5/R11）。
- 生命周期：`state/runtimeStore.ts` 的 `ViewerLifecycle`（idle/initializing/ready/recovering/failed/disposed）是控制流唯一依据，`status` 仅为展示文案。
- 门禁：ARCH-11/R7（渲染层不 import React/Query/Zustand/XState/features）、R9（ScenePort 必需能力）、R10（含 type-only 边无环）；GPU 证据见 `docs/evidence/`。

本次初始化仅代表工程边界已建立。具体实现状态见 `../IMPLEMENTATION-STATUS.md` 与 `../architecture.md` §30。
